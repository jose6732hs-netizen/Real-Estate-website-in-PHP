## 🎯 Como Usar Agora

### Para Criar o PR:

**Opção 1 - CLI (Rápido)**
```bash
gh pr create --title "feat: modernizar para Next.js 15" \
  --body-file PR_DESCRIPTION.md \
  --base main \
  --head projeto-javascripttypescript
```

**Opção 2 - Interface Web (Recomendado)**
1. Acesse: https://github.com/jose6732hs-netizen/Real-Estate-website-in-PHP
2. Clique "Pull requests" → "New pull request"
3. Selecione: base=`main`, compare=`projeto-javascripttypescript`
4. Cole: Conteúdo de `PR_DESCRIPTION.md`
5. Clique "Create pull request"

### Para Testar Localmente:

```bash
# 1. Instalar
npm install

# 2. Configurar
cp .env.example .env.local
# Editar DATABASE_URL

# 3. Migrations
npm run prisma:push

# 4. Rodar
npm run dev

# 5. Abrir
http://localhost:3000
```
